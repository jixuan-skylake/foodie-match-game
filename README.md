# 🍔 吃货大作战

> 一款类似"抓大鹅"的美食主题三消堆叠小游戏

## 游戏玩法

1. **点击收集** - 点击场上的美食卡片，卡片会进入底部槽位
2. **三消消除** - 当槽位中有3个相同的美食时，自动消除得分
3. **策略选择** - 槽位最多7个，满了就游戏结束
4. **通关目标** - 清除场上所有卡片即可过关

## 特色

- 🍕 **美食主题** - 火锅、烤肉、奶茶、炸鸡...各种美食等你收集
- 🎮 **简单上瘾** - 一键操作，随时随地玩
- 🏆 **分数挑战** - 挑战更高分数，成为最强吃货

## 技术栈

- 微信小游戏原生开发
- 纯 JavaScript + Canvas 2D
- 无第三方引擎依赖

## 运行方式

1. 下载微信开发者工具
2. 导入项目目录
3. 点击预览即可运行
